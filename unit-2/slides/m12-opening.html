The memory hierarchy

  • Caches: lower capacity and faster access than main memory
  • GPU memory is separate; the connecting link has lower bandwidth
Notes. The numbers above L2, L3, and main memory are effective bandwidths estimated from useful array traffic. Each float32 addition reads 8 bytes and writes 4, giving 12 bytes per addition. np.add uses one core in this experiment. NVIDIA's T4 data sheet specifies 16 GB of GPU memory at 300 GB/s. Its PCIe link provides 32 GB/s across both directions, or 16 GB/s each way.
