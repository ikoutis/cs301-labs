Standardization

Every column is brought to mean 0 and standard deviation 1, so that columns on different scales can be compared. For column j:

μj=1n∑i=1nxijσj=1n∑i=1n(xij−μj)2zij=xij−μjσj
  • Divide by n, as NumPy's std does. (pandas divides by n − 1.)
  • A program that follows the three formulas with loops visits every number three times: 3 × n × m visits.
  • Dataset 7: 3 × 459,327 ≈ 1.4 million visits. At 100 nanoseconds a visit, about 0.14 seconds. Keep that guess.

Version 1: loops on Python lists

def standardize_loops(rows):
    n = len(rows)
    m = len(rows[0])
    means = [0.0] * m
    for j in range(m):
        total = 0.0
        for i in range(n):
            total += rows[i][j]
        means[j] = total / n
    stds = [0.0] * m
    for j in range(m):
        total = 0.0
        for i in range(n):
            d = rows[i][j] - means[j]
            total += d * d
        stds[j] = math.sqrt(total / n)
    result = []
    for i in range(n):
        new_row = []
        for j in range(m):
            new_row.append((rows[i][j] - means[j]) / stds[j])
        result.append(new_row)
    return result

Written by an AI assistant to stated requirements: lists only, no NumPy, divide by n, return a new list and leave the input as it was.

Version 2: the same loops on a NumPy array

def standardize_array_loops(X):
    n, m = X.shape
    means = [0.0] * m
    for j in range(m):                   # first pass: the mean of each column
        total = 0.0
        for i in range(n):
            total += X[i, j]
        means[j] = total / n
    sds = [0.0] * m
    for j in range(m):                   # second pass: the standard deviation of each column
        total = 0.0
        for i in range(n):
            d = X[i, j] - means[j]
            total += d * d
        sds[j] = math.sqrt(total / n)
    Z = np.empty((n, m))                 # a new array for the results
    for i in range(n):                   # third pass: the new entries
        for j in range(m):
            Z[i, j] = (X[i, j] - means[j]) / sds[j]
    return Z

Two differences: X[i, j] in place of rows[i][j], and a result array made with np.empty((n, m)). Faster or slower than the lists? Write down your guess.

Version 3: one operation on a whole array

v = np.array([1.0, 2.0, 3.0, 4.0])
print("v      =", v)
print("v + 10 =", v + 10)        # 10 is added to every entry
print("v * v  =", v * v)         # each entry is multiplied by itself
print("sum    =", v.sum())
print("mean   =", v.mean())

v      = [1. 2. 3. 4.]
v + 10 = [11. 12. 13. 14.]
v * v  = [ 1.  4.  9. 16.]
sum    = 10.0
mean   = 2.5

NumPy applies an operation to every entry of an array in one call. A computation written this way, with no Python loop over the entries, is vectorized. The loop still exists; it runs inside NumPy.

Standardization, vectorized, and broadcasting

def standardize_vectorized(X):
    mu = X.mean(axis=0)          # the m column means
    sigma = X.std(axis=0)        # the m column standard deviations
    return (X - mu) / sigma      # broadcasting: n rows and m columns, combined with m numbers

shape of X:      (41757, 11)
shape of mu:     (11,)
shape of X - mu: (41757, 11)
  • X.mean(axis=0) runs down the rows and leaves one number for each column: m numbers.
  • X - mu subtracts m numbers from an array with n rows and m columns. NumPy subtracts mu[j] from every entry of column j, as if the m numbers were written again on every row. That rule is broadcasting.
  • The division by sigma works the same way. The three loop passes of Versions 1 and 2 are what this one line replaces.

Measure the three versions

def average_time(function, data, repeats=5):
    """The average time of one call function(data), in seconds, over several calls."""
    total = 0.0
    for _ in range(repeats):
        start = time.perf_counter()              # the clock before the call
        function(data)
        total += time.perf_counter() - start     # the time that this call took
    return total / repeats

The three times

Why the times differ

  • What Python does for each pass of a loop. The interpreter reads several bytecode steps, looks up each name, inspects the type of each value to decide what - and / mean, and creates a new object for each result: 24 bytes for a decimal number, 8 more for its place in a list.
  • What NumPy does for one operation. The array is one block of 8-byte numbers of one type. X - mu is a single call into compiled code, whose loop does no lookup and builds no object, and one instruction can handle several numbers.
  • Why the loops on the array are the slowest. The loop still runs in the interpreter, and each read of X[i, j] builds a new Python object for one number of the block.

An array is fast when the loop over its numbers runs inside NumPy.
